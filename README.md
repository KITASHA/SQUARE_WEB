# SQUARE 公式サイト

岡山アカペラサークル SQUARE の静的サイトです。Cloudflare Workers Static Assets で公開します。
Bootstrap は使用せず、HTML + CSS + JavaScript だけで構成しています。

## 公開ページ

| URL | 内容 |
| --- | --- |
| / | トップページ |
| /homes/about | SQUAREについて |
| /homes/show_1 | 定期活動会 |
| /homes/show_2 | Okayama Music SQUARE |
| /homes/show_3 | スターターバンド制度 |
| /homes/join | 入会について |

## ファイル構成

```text
public/
├─ index.html
├─ 404.html
├─ robots.txt
├─ homes/
│  ├─ about.html
│  ├─ join.html
│  ├─ show_1.html
│  ├─ show_2.html
│  └─ show_3.html
└─ static/
   ├─ css/
   │  └─ style.css
   ├─ js/
   │  └─ site.js
   ├─ images/
   ├─ icons/
   │  ├─ favicon.ico
   │  └─ apple-touch-icon.png
   └─ manifest.json
```

普段のデザイン変更は `public/static/css/style.css`、共通ヘッダー・フッターは `public/static/js/site.js`、画像は `public/static/images/` を編集します。

色は `style.css` 冒頭の `--sq-*` CSS変数にまとめています。グレーから青や緑に変更する場合も、基本的にはここを変更すれば全ページに反映されます。

## 開発・確認

Node.js 24以上を使用します。

```sh
npm ci
npm run validate
npm run dev
```

ローカル起動後は通常 `http://localhost:8787` で確認できます。

## Cloudflare

`public/` を Static Assets として配信し、`src/index.js` は旧URLのリダイレクトとセキュリティヘッダーを担当します。

仮公開では `wrangler.jsonc` の `PREVIEW=true` により `X-Robots-Tag: noindex, nofollow` を付与し、`robots.txt` でもクロールを止めています。本番公開時は検索公開方針に合わせて変更してください。

```sh
npx wrangler login
npm run deploy
```

## バンド情報連携：Phase 1仕様（2026-09-19）

以下は合意済みの運用方針と実装予定です。API・一覧ページ・Google連携はまだ未実装です。

### 登録と更新

- 新規Googleフォームを作り、URLを知っている人がGoogleアカウントでログインして投稿できるようにします。組織内限定・回答1回限定にはしません。
- 管理者の承認は不要です。新規データの公開は初期値TRUEとし、検証・同期が成功した情報を自動掲載します。
- 管理者は「公開」をFALSEにして掲載を停止できます。回答の再編集・再同期では、このFALSEをTRUEへ戻しません。
- 更新には送信完了画面の回答編集リンクを使用します。登録者にはリンクを保存してもらいます。
- 回答編集リンクは、知っている人が編集できるリンクです。本人専用のログイン認証とは異なり、サイトや公開APIへ掲載しません。
- フォームの回答IDと固定のバンドIDを対応させ、編集時は同じバンドを更新します。名前やシート行番号で対象を特定しません。
- 新しい回答は別バンドとして扱います。編集リンクを紛失した場合は管理者へ連絡する運用です。
- 通常時はデータ同期完了から最大約5分で反映するキャッシュを予定します。画像処理やGoogle側の障害による遅延は別途扱います。

### フォーム項目

フォーム名は「SQUARE バンド登録・更新」とします。新規登録／更新依頼の質問は設けず、更新は回答編集で行います。

| 質問名 | 形式 | 必須 | 設定案 |
| --- | --- | --- | --- |
| バンド名 | 記述式 | はい | 最大80文字 |
| メンバー | 段落 | はい | 公開する名前・パート。最大1000文字 |
| 紹介文 | 段落 | はい | 最大2000文字 |
| ジャンル | 記述式 | いいえ | 最大100文字 |
| Instagram | 記述式 | いいえ | httpsのプロフィールURL |
| X | 記述式 | いいえ | httpsのプロフィールURL |
| YouTube | 記述式 | いいえ | httpsのチャンネル等のURL |
| その他SNS | 記述式 | いいえ | httpsのURLを1件 |
| バンド画像 | ファイルのアップロード | いいえ | 画像1枚、最大10MB。配信対応形式はJPEG・PNG・WebPを予定 |
| 掲載への同意 | チェックボックス | はい | 「入力したバンド情報・画像がWebサイトに自動掲載されることに同意します」 |

説明文：

> SQUAREのバンド紹介ページへ掲載する情報を登録してください。管理者の承認を挟まず自動掲載されます。メンバー名・紹介文・画像には公開してよい内容を入力してください。更新には送信後の「回答を編集」リンクを使いますので、リンクを保存してください。リンクは他の人へ公開しないでください。

設定は「回答の編集を許可」をオン、「回答を1回に制限」「結果の概要を表示」をオフにします。メールアドレス収集は初期構成では不要です。画像アップロードに伴うGoogleログインは必要です。フォームは接続試験が完了してからメンバーへ案内します。

### スプレッドシート

同じ非公開スプレッドシート内で、Googleが作る回答タブと、Apps Scriptが同期する「バンド」タブを分けます。回答タブの列を手で並べ替える必要はありません。

「バンド」タブの列：

| 列名 | 入力元・用途 |
| --- | --- |
| ID | 自動生成する固定ID |
| 回答ID | Googleフォームの回答ID。更新対象の照合用・非公開 |
| 登録日時 | 初回登録時に保存し、編集で変更しない |
| 更新日時 | 最終同期した更新の日時 |
| バンド名 | フォーム回答 |
| メンバー | フォーム回答 |
| 紹介文 | フォーム回答 |
| ジャンル | フォーム回答 |
| Instagram | フォーム回答 |
| X | フォーム回答 |
| YouTube | フォーム回答 |
| その他SNS | フォーム回答 |
| 画像ファイルID | Driveの画像参照・非公開 |
| 画像URL | Phase 4で自動記入。手入力不要 |
| 画像処理状態 | 画像なし／未処理／完了／エラー |
| 公開 | 新規だけTRUE。管理者が変更でき、同期で上書きしない |
| 表示順 | 管理者が任意入力。数値昇順、空欄は末尾、同順はID順 |

公開APIは掲載に必要な項目のみ返します。回答ID、DriveのファイルID、編集リンク、内部エラーなどは返しません。フォーム入力値をシートに書く際は数式として実行されないように扱います。

Phase 2〜3は画像なしで先に検証できます。画像転送失敗時にも人による承認待ちにはせず、画像なし表示または既存画像の維持と再処理を予定します。

### 接続方法と準備

データは「Forms → 非公開Sheets → Sheets API → Workerの /api/bands → 一覧ページ」とします。Google CloudでSheets APIと専用サービスアカウントを用意し、対象スプレッドシートだけを閲覧共有します。認証情報はCloudflare Secretsへ保存し、コード・会話へ貼りません。

画像はPhase 4で「Drive → Apps Script → 認証付きWorker受付 → 非公開R2」へ接続します。既存画像はStatic Assetsのままです。

最初に管理者が行う準備：

1. 継続管理するGoogleアカウントで上記フォームを新規作成する。
2. フォームの回答先として新しいスプレッドシートを作成する。シートは一般公開しない。
3. フォームの編集画面URLとスプレッドシートURLを作業担当者へ伝える。URLを伝えるだけでは編集権限は付与されない。

次段階で行う準備：Google CloudのAPI・サービスアカウント設定、Cloudflare Secrets登録、Apps Script設置・初回権限承認・トリガー設定。R2はPhase 4で用意します。

フォーム回答IDを使う同期では、初回送信・回答再編集・再実行の重複防止・管理者の非公開設定維持を実フォームで検証します。Google側の権限や画像形式制限も、この接続試験で確認します。

参考：[Google Formsの共有設定](https://support.google.com/docs/answer/2839588)、[回答IDと編集リンク](https://developers.google.com/apps-script/reference/forms/form-response)、[Apps Scriptのインストール型トリガー](https://developers.google.com/apps-script/guides/triggers/installable)。
